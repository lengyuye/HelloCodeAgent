# 智能代码审查助手

> 自动分析代码质量、发现潜在 bug、提出优化建议
> 个人学习Agent 练习使用

## 📝 项目简介
- 解决什么问题？
    代码审查是软件开发中的重要环节，但人工审查耗时且容易遗漏问题。现有的静态分析工具只能发现语法错误，无法理解代码逻辑，因此需要一个能够理解代码语义、提供深度分析的智能助手。
- 有什么特色功能？
    该项目将实现代码质量分析（检查代码风格、命名规范、注释完整性）、潜在 bug 检测（发现逻辑错误、边界条件问题、资源泄漏）、性能优化建议（识别性能瓶颈、提出优化方案）。
- 适用于什么场景？
    日常开发

## ✨ 核心功能

- [ ] 功能1: 自动分析代码质量、发现潜在 bug、提出优化建议
- [ ] 功能2: 可以结合项目内部知识库，提出符合项目要求的建议
- [ ] 功能3: 有记忆功能，可以记忆用户习惯等

## 🛠️ 技术栈

- HelloAgents框架
- 使用的智能体范式（ReAct、Reflection）
- 使用的工具和API(代码切片工具tree_sitter)

## 🎯 项目亮点

- 亮点1:多Agent+调用工具+记忆+RAG
- 亮点2:使用了ReAct范式，使Agent可以调用代码切片工具对要审查的代码进行预处理，同时观察处理后的结果，对处理后的代码进行审查。
- 亮点3:使用了Reflection范式，当Agent得出审查结果后，再用另一个Agent对审查的结果进行评估和反馈，直到评估没有问题
- 亮点4:把用户和Agent的对话，存入记忆，比如可以记忆用户的代码习惯等等。每次对话时，可以检索记忆。
- 亮度5：RAG读取项目内置的文档，可以作为知识库来辅助代码审查，比如data目录下的code_standard.txt
