# 这是项目自己的代码规范

1. 导入（import）
每个 import 独占一行，不要写 import os, sys。
导入顺序：标准库 → 第三方库 → 本地模块，每组之间用空行分隔。
尽量使用绝对导入，避免相对导入的复杂性。
不推荐使用 from module import *，除非明确需要（如交互式环境）。

2. 注释与文档字符串
注释：使用 # 加一个空格，与代码同行时至少空两格。解释“为什么”而非“做什么”（代码本身应能说明做什么）。
文档字符串：每个公共模块、类、函数都应包含 docstring，使用三引号 """。推荐 reStructuredText 或 Google/NumPy 风格，至少说明功能、参数和返回值。
